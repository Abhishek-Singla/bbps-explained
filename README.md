# BBPS (Bharat Connect) explained

Plain-language notes on how India's Bharat Bill Payment System works, written from a product manager's point of view and checked against the official sources listed in [SOURCES](SOURCES.md): the RBI's BBPS Directions, 2024 and NBBL's public website.

> NBBL's website now uses both "Bharat BillPay" and "Bharat Connect" for the same service. Older documents and many systems still say BBPS, so all names appear here.

## How to read the notes
- Statements marked with an RBI paragraph or attributed to NBBL's site come from those sources.
- Sections labelled "practitioner notes" or "illustrative" are my own explanations, not published rules.
- Where I could not find something in an official source, the notes say so instead of guessing.

## What this is not
- Not official documentation. For rules, message formats and timelines, use the RBI Directions and the specifications and operating guidelines issued by NBBL.
- Contains no data, designs, APIs or numbers from any employer, bank or client.

Corrections are welcome through an issue.
